# Implementation Plan: Custom Namespace-Managed Resources

**Branch**: `001-custom-namespace-crds` | **Date**: 2026-10-10 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/001-custom-namespace-crds/spec.md`

## Summary

Add three namespaced CRDs to the existing kubebuilder v4 operator (group `custom.jurikolo.name/v1`): `CustomNamespace` (manages a real Namespace of the same name from `default`), `CustomDeployment` (minimal Deployment: name, image, replicas, gated on an existing CustomNamespace), and `CustomConfig` (ConfigMap parity, gated the same way). Each kind gets one reconciler that creates/repairs its real resource, reports success/failure via status conditions, guards deletion with finalizers, and stamps owner labels for cascade delete and name-conflict detection. Schema-level rules (required fields, reserved names, replicas ≥ 0, immutable namespace reference) are enforced by CRD validation, not webhooks.
